DEMO_PLACEHOLDER

This repository includes a small helper script to generate a tiny 1-second MP4 demo video.

Generated file path (after running the script):
  assets/demo/demo.mp4

How to generate locally:
  1. Install ffmpeg (https://ffmpeg.org/). On macOS: `brew install ffmpeg`; on Ubuntu: `sudo apt-get install ffmpeg`.
  2. Make the generator executable once:
       chmod +x assets/demo/generate_sample_mp4.sh
  3. Run the generator script:
       ./assets/demo/generate_sample_mp4.sh

Why we use a generator instead of committing a binary:
  - Keeps the repository small and avoids inflating Git history with binary blobs.
  - Allows CI or contributors to reproduce the demo deterministically.
  - Replace the generated demo with a real recording by committing your MP4 to the same path if desired.
